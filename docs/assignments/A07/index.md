## Chart Recording Data from Inner and Outer Loops

<img src="A7-Loops.png" style="border-radius: 12px; width: 100%;">

I made 3 outer loops to strengthen the overall bracket before going into the inner loops using studies 3, 4, and 5.

The table above shows the changes made after each outer loop to strengthen the part, like adding chamfers and so on. 

From all 3 inner loops it was shown that increasing the mesh size did not allow for safety factor or stress to converge on any of the 3 inner loops taken. However, displacement was convergent for all 3 loops. 

From this I can conclude that the part will still function because its displacement is not increasing exponentially. 

## Reflections

From this assignment I learned how to interpret the information found using FEA's and how to use that information to strengthen an overall part I am designing. I learned how finer meshes give a higher degree of accuracy, but also take longer to compute given their increased complexity.
